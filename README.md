# Kenya Bank Profitability Analysis

## Overview
Analysis of profitability metrics across Kenyan commercial banks using Python.

## Contents
- Data cleaning and preparation
- Exploratory data analysis
- Visualizations
- Predictive modelling (XGBoost)

## Requirements
- Python 3.10
- pandas
- matplotlib
- scikit-learn
- xgboost

## How to Run
Open `Kenya_Bank_Profitability_Analysis.ipynb` in Jupyter or VS Code and run all cells.
